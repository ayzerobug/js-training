Weather App

Build a working weather app that fetches live data from a public API and displays it on the page.

📅 Session 27
📁 index.html + script.js
⏱️ Solo task

🌐 The API

You will use Open-Meteo — a free, public weather API that requires no sign-up and no API key.

Endpoint (Lagos):

https://api.open-meteo.com/v1/forecast?latitude=6.5244&longitude=3.3792¤t_weather=true

Sample response:

{ "current_weather": { "temperature": 31.2, // degrees Celsius "windspeed": 14.5, // km/h "weathercode": 3, // condition code (see tip below) "time": "2026-08-12T10:00" // current time } }
💡 Weather codes: 0 = Clear sky, 1–3 = Partly cloudy, 45–48 = Foggy, 51–67 = Rainy, 71–77 = Snowy, 80–82 = Showers, 95+ = Thunderstorm. Use these to show a relevant emoji or label on the page.

1 Fetch & Display the Weather

Write an async function that fetches weather data from the API and displays the following on the page:

  • City name — hardcode "Lagos" for now
  • Current temperature in °C
  • Wind speed in km/h
  • A weather condition label based on the weathercode (e.g. "Clear sky", "Rainy", "Cloudy")
💡 Access the data with data.current_weather.temperature, data.current_weather.windspeed, and data.current_weather.weathercode.

2 Add a Loading & Error State

The user should always know what's happening:

  • Show a loading message while the fetch is in progress
  • Show the weather data when the fetch succeeds
  • Show a friendly error message if the fetch fails

3 Add a Refresh Button

Add a "Refresh Weather" button on the page:

  • Clicking the button calls your fetch function again and updates the displayed data
  • The button should be disabled while fetching and re-enabled when done
  • Use finally to re-enable the button whether the fetch succeeds or fails

4 Save Last Fetched Data to localStorage

Use what you learned this session to persist the weather data:

  • Every time you successfully fetch new weather data, save it to localStorage
  • When the page loads, check if there is saved weather data in localStorage and display it before the first fetch completes
  • This way the user sees something immediately instead of a blank page
💡 Save with JSON.stringify() and retrieve with JSON.parse() || null. If saved data exists, render it first, then fetch fresh data in the background.

Rules

  • Use async/await for your fetch function — not .then()/.catch()
  • Use try/catch/finally to handle loading, success, and error states
  • Do not use any external libraries — vanilla JS only
  • Test in the browser before submitting — the page must load with no console errors
  • Submit both your index.html and script.js files
